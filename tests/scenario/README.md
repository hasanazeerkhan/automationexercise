# Scenario Tests

Put tests here when they implement a numbered test case or a clearly defined business scenario, especially where the expected steps and outcome come from a scenario list. Keep each scenario's setup, actions, and assertions together; use descriptive test names so the scenario is easy to identify.

`testCases.spec.js` groups numbered account scenarios: registering a user, logging in with valid or invalid credentials, logging out, and attempting registration with an existing email.
